# 用自己的购物清单试一轮

直接把下面这段发给支持联网查询的 AI 助手，即可先试一次手动研究；不安装 Skill 也能使用这段独立提示词。安装后可以通过 `$deal-radar` 反复调用完整工作流。实际搜索与核验耗时取决于助手和商家网站。

以下是**虚构的演示偏好**，请换成自己的需求。第一次直接在聊天中输出，不需要 Notion 或日历。

```text
帮我按下面的要求，手动查一轮好价。如果已安装 deal-radar，请使用该 Skill。

以下是我的购物需求：
- 收货地区：德国。
- 想买：一台 24–27 英寸的日常办公显示器、一盏可调光台灯。
- 总预算：300 欧元，显示器优先；不必为了花完预算凑单。
- 偏好：外观简洁，黑色、白色或灰色；显示器需要 HDMI，支架可调高度更好。
- 不考虑：二手商品、跨境税费不明确的商家。
- 优惠重点：找实际有明显价格优势的商品；暂时不够划算的，给出有理由的观望目标价。

本轮最多选 3 个候选，直接在聊天中展示。先从官网、可靠购物平台或优惠社区找线索，再回商家核对：
1. 具体型号、规格、现价、运费和可确认的到手价。
2. 当前库存、退换条件、优惠码门槛与官方截止日期。
3. 与同款可核验价格相比，为什么值得买或值得等。
4. 商品直链、核验时间，以及仍然不确定的地方。

分成“值得考虑 / 观望 / 线索待核验”，没有合适的就如实说。
无法核验的字段标“待核验”；建议目标价和实际查到的历史价格分开写。
本轮仅手动运行，在聊天中给结果。
```

想换成服饰、鞋包、电子产品或家居用品，只需替换需求部分。服饰补充尺码或实量数据，鞋子补充品牌尺码对应；无法确定时保留待核验。

手动试用满意后，再按 README 单独配置定时更新。Notion 归档与日历提醒也需要连接相应工具并授权；安装 Skill 本身不会创建定时任务或日历事件。
