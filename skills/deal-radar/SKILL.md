# 好价雷达 Deal Radar

先找到适合用户的商品，再判断是否便宜。交付少而有证据的候选；折扣很大但不合需求、尺码或总预算的商品不进入主推荐。

## 确定本次范围

从当前对话和用户指定的私人清单读取偏好。先确认收货国家、币种、总预算、商品类别，以及真正影响筛选的风格、尺码、二手接受度；已有信息不重问。只问会阻碍本次研究的缺口，其他未知项明确保留。

不默认用户所在国家、性别、体型或预算。衣裤尺码未知时给出需要比对的品牌尺寸表或实量，不凭身高体重猜码。鞋码按具体品牌与性别系列转换；某个尺码出现在网页上不等于有库存，“可加入购物袋”仅是可购信号，不是锁定库存或结算成功。实际尺码不符的款排除；尺码可选但合脚度尚需确认的款可保留并说明。通勤包是否装得下电脑，要核对电脑尺寸、包内尺寸及开口。

需要建立长期偏好、保存结构化候选或做同款去重时，读 [references/profile-and-record.md](references/profile-and-record.md)。普通一次性查询不必创建配置文件。

## 找线索，再核验

1. 以可用的联网搜索、商户官网、可靠零售平台和当地优惠社区发现候选；例如英国可看 HotUKDeals。品牌名单随用户风格和地区调整。
2. 社区帖子、聚合页与搜索摘要只是线索。打开对应商户商品页，核对具体型号、颜色、尺码、现价、库存、促销条件及退换货。官方页面无法读取时，可用当前环境支持的浏览器核验；仍无法证实时降为“线索待核验”。
3. 明确区分商户划线价、实际历史成交价与建议目标价。记录基准的来源与日期；没有可靠历史记录就写“历史低价未核实”。不得将划线价自动当作市场常价，或将建议目标价写成历史低价/必然降价预测。
4. 核算符合用户条件的实际到手价：商品 + 必需运费 + 已知税费/进口费用 − 已证实可用优惠。学生、新客、会员和用码条件逐项说明；未经核实不能声称叠加成功。返现、积分和礼品单列，不直接从支付金额扣除。费用未知时给出已知部分与缺口。
5. 排除过期活动、其他地区价格、不同款式的低价、未来日期索引及仅剩不适合尺码的“低至”价。显示更新时间不代表促销当前有效。

引用商品直链和支持关键条件的页面，记核验日期、当地时间与时区。旧记录缺时区时保留未知，不能附会成用户当地时区。换币时使用可验证汇率并附汇率日期和来源；周末只能拿到最近公布值时明确其日期，人民币或其他换算仅作估价，卡组织/支付服务实际结算另计。

## 按价值排序

与用户需求的匹配度是入选门槛；在合适的候选中优先比较真实价差、材质/做工、使用频率、退货成本与总预算占用。质感基础款和偏审美的平价款可分别比较，避免只按折扣百分比排序。

若用户强调“大羊毛”，可暂用以下**筛选起点**，并随品类和真实市场基准调整：质感服饰降价约 40%–60% 或更多，快时尚五折或更低，皮鞋降价约 30%–40%。这些是筛选建议；仅达到商户划线折扣门槛，不能宣称真实价差已核实。平时很少降价的款也可因有证据的价格优势入选。

给候选标注：

- **值得考虑**：适配、当前价格和必要条件已有证据，尺码或容量仍有缺口时明确写出购买前要完成的检查。
- **观望**：款式适合，但价格优势不足；给一个有理由的建议目标价或等待条件，说明可能不降价或先售罄。
- **线索待核验**：关键价格、库存、来源或规则缺证，不写成有效优惠。

主清单优先呈现大折扣与明确变化；普通小优惠可以省略或放候补。不为凑数添加商品。无合适结果时直接说明本次没有已核实的大羊毛，可保留少量值得等价的款。

二手商品还需核对成色、磨损、配件、卖方性质、来源、平台验真范围及退货承诺。区分卖方描述、平台承诺与独立鉴定，不能将平台上架等同于已独立验真。

## 可选保存、提醒与重复运行

默认在聊天交付结果。只有用户要求时才创建/更新 Notion 或其他外部清单、购物日历提醒或定时任务；沿用用户已明确给出的授权范围，不重复索要同一授权。

涉及这些动作时，先读 [references/connected-workflow.md](references/connected-workflow.md)。使用当前环境实际提供且已连接的官方工具/连接器；能力不足时再用受支持的浏览器。Skill 不包含服务凭据，不自带账号连接或定时执行服务。

安装 Skill、连接服务、写入清单、创建日程、配置定时任务和定时任务实际成功执行是不同状态。分别以工具返回和必要回读确认；无法完成就说明完成到哪一步，不宣称后续状态已成功。

## 交付

用用户的语言先给最值得看的候选和理由，随后列到手价、折扣基准、尺码/库存、条件、截止日期、来源和未核实项。简短提示它如何占用总预算。无明确商家截止日就写“待商家公布”，不把黑五日期或库存紧张当成购物 DDL。

本流程用于研究和整理。购买、下单、对外发帖或向他人发送消息，需要用户对对应动作另有明确授权。私人偏好、清单链接、账户信息和事件标识不能带入公开分享的 Skill 或演示材料。
