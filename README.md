# 好价雷达 · Deal Radar

让 AI 按你的需求找好价：先判断适不适合，再核对折扣是不是真的。

作者：**Blake Yuan** · 版本：**0.1.0** · [MIT License](LICENSE)

Deal Radar 是一套可审阅的 Agent Skill。它把购物需求、同款比价、优惠条件和购买截止日放在同一个工作流里，适合黑五、换季和有计划地添置物品。

## 先试一次

不需要先连接 Notion 或日历。准备一个能联网搜索的 AI 助手，复制 [试用提示词](launch/try-it-prompt.md)，填入你的品类、收货地区、预算与偏好，先生成一份手动清单。

没有联网能力时，只能基于你提供的商品页面或截图分析，不能核验实时优惠。

## 安装 Skill

下载本项目，将 `skills/deal-radar` 整个文件夹放入所用 Agent 支持的技能目录。Codex 的用户级目录为 `~/.codex/skills/`；安装后在新会话使用 `$deal-radar`。

也可以使用 Skills CLI：

```sh
npx skills add yuanztapply/deal-radar --skill deal-radar
```

CLI 的运行环境与安装方式以 [官方说明](https://github.com/vercel-labs/skills) 为准。选择你实际使用的 Agent；不同宿主的工具连接需分别设置。

## 它会做什么

- 先问清或采用你已给出的用途、风格、预算、地区、尺码与新旧接受度。
- 从官网和可靠零售商核验商品，优惠社区只作为发现线索的入口。
- 区分同款真实价差、商户划线价和未经验证的叠加优惠。
- 将运费、资格门槛、尺码库存、退货费用和截止日期放入判断。
- 分开记录“现在值得考虑”与“等深折扣”，保留价格观察记录。
- 二手商品按同款、成色、来源及退换条件比较，不拿全新原价夸大折扣。

服饰的初始筛选偏向大折扣，但门槛可调整。折扣数字不能代替材质、适配度和实际用途。鞋码缺货或尺寸未知时只列候选，不声称适合你。

## 可选的长期使用

**Notion 归档**：你明确要求后，使用你自己的已连接账号创建或更新购物文档；没有连接也能在聊天中使用。

**截止日提醒**：你明确授权后，为商家已公布的截止日期设置提前提醒。日期或结束时刻未知时如实标注，不猜一个截止时间。

**每日更新**：Skill 本身不是后台服务。需要另行设置所用 AI 工具支持的定时任务，并确认时区、权限、运行环境和实际触发。安装 Skill 不等于创建了自动化。

## 首次使用示例

> 用 $deal-radar 帮我挑秋冬通勤服饰和一双皮鞋。先只做一次手动搜索，按我的预算与风格核对真实优惠。原价款放候补，尺码未确认的单独标出来。先在聊天里给我最多五个值得继续看的候选。

请继续补充自己的收货地区、预算、尺码和偏好。示例不预填任何真实用户的资料。

## 能力与实际验证

这是技能说明与模板，不是独立购物 App，也不提供商品库存数据库或支付功能。

发布包的检查范围见 [验证记录](VALIDATION.md)。不同 Agent、网站、地区和连接器的表现可能不同；一次网站核验只代表当时的页面信息。

## 文件

- `skills/deal-radar/`：可安装 Skill 与按需参考材料。
- `launch/try-it-prompt.md`：无需安装的首次试用提示词。

本项目没有附带作者的私人购物文档、账号连接、个人档案或已有日程。试用者连接自己的账号，并只保存自己愿意保存的信息。
